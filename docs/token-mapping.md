# 토큰 매핑표

`apps/docs`·`packages/ui`에 남은 arbitrary 값 **343건**을 성격별로 묶은 표입니다.
4px 그리드 기준으로 가장 가까운 스케일을 제안했고, `결정` 칸은 사람이 채웁니다.

관련: 결정 원장 **L-011**(토큰 전용), `eslint.config.mjs`(예외 정책)

## 사용법

1. 시안을 받으면 먼저 이 표에서 값을 찾는다.
2. 있으면 토큰, 없으면 아래 `결정 규칙`으로 처리한다.
3. 스케일을 확장했다면 `primitives.json`에 추가하고 Figma Variables로 동기화한다.
4. 결정한 내용을 이 표에 반영한다(결정 칸 채우기).

## 결정 규칙

| 차이                 | 처리                                                             |
| -------------------- | ---------------------------------------------------------------- |
| 0px                  | 토큰 유틸리티로 교체                                             |
| ±1~2px               | 가까운 토큰으로 **스냅** (광학 차이 무시 가능)                   |
| ±3px 이상 · 3회 이상 | **스케일 확장** 검토 (원장 L-011에 기록, Figma Variables 동기화) |
| ±3px 이상 · 1~2회    | **예외 유지** (사유를 코드 주석으로)                             |

## 왜 이 표가 필요한가

Figma Variables에 있는 값은 플러그인·MCP가 자동으로 넘겨줍니다.
없는 값은 아무도 결정하지 않아 arbitrary 클래스로 남습니다.
이 표가 그 결정 지점이고, 토큰이 늘어날수록 표는 짧아집니다.
