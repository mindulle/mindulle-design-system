# 토큰 매핑표

`apps/docs`·`packages/ui`에서 **토큰화 대상**인 arbitrary 값 **112건**을 성격별로 묶은 표입니다.
린터 기준 전체는 더 많지만, 측정폭(`ch`)·행간(`leading`)·CSS 속성·헤어라인은 아래 `영구 예외`로 분류해 여기서 세지 않습니다.
4px 그리드 기준으로 가장 가까운 스케일을 제안하고, `결정` 칸은 `docs/token-decisions.json`에서 옵니다.

> 이 파일은 생성물입니다. 직접 고치지 말고 `pnpm run tokens:map`으로 다시 만드세요.

관련: 결정 원장 **L-011**(토큰 전용), `eslint.config.mjs`(예외 정책)

## 사용법

1. 시안을 받으면 먼저 이 표에서 값을 찾는다.
2. 있으면 토큰, 없으면 아래 `결정 규칙`으로 처리한다.
3. 스케일을 확장했다면 `primitives.json`에 추가하고 Figma Variables로 동기화한다.
4. 결정한 내용을 `docs/token-decisions.json`에 적고 `pnpm run tokens:map`을 다시 돌린다.

## 5. 영구 예외

| 패턴             | 이유                                      | 예시             |
| ---------------- | ----------------------------------------- | ---------------- |
| `max-w-[Nch]`    | 측정폭 — 글자 수 기준이라 px 토큰 불가    | `max-w-[38ch]`   |
| `leading-[N]`    | 디스플레이 행간 광학 보정                 | `leading-[0.94]` |
| `[hyphens:none]` | CSS 전용 속성                             | `[hyphens:none]` |
| `gap-[2px]`      | 1px/2px 헤어라인 그리드 (브랜드 2px 규칙) | `gap-[2px]`      |
| `text-[44~78px]` | 디스플레이 스케일 — 히어로 헤딩           | `text-[56px]`    |

## 결정 규칙

| 차이                 | 처리                                                       |
| -------------------- | ---------------------------------------------------------- |
| 0px                  | 토큰 유틸리티로 교체                                       |
| ±1~2px               | 가까운 토큰으로 **스냅**                                   |
| ±3px 이상 · 3회 이상 | **스케일 확장** (원장 L-011 기록 + Figma Variables 동기화) |
| ±3px 이상 · 1~2회    | **예외 유지** (사유를 코드 주석으로)                       |

## 토큰을 새로 만들 때

```text
1. packages/tokens/tokens/primitives.json 수정
2. pnpm --filter @mindulle/tokens build
3. Figma Variables 동기화
4. pnpm run tokens:map  (이 표 갱신)
5. 원장 L-011에 사유 기록
```

5단계를 건너뛰면 표가 실제 코드와 어긋나고, 그 순간 표는 신뢰를 잃는다.
