# 🏛️ Sonagi & Mindulle Visual Identity Charter

> **소나기 생태계 시각 정체성 및 그래픽 스타일 최상위 헌법 (SSOT)**  
> 최초 제정: 2026-11-13  
> 적용 범위: 소나기 공방 전사 (`sonagi-design-system`, `blog-sonagi-space`, `sonagi-portfolio`, `llm-wiki`)

---

## 1. 우리의 본질 (Core Manifesto)

> **"소나기는 현대적인 소프트웨어 엔지니어링 공방이자,  
> 잉크 냄새와 종이의 물성이 살아 숨 쉬는 단단한 에디토리얼 가제트(Editorial Gazette)이다."**

우리는 가상의 판타지 세계관이나 박물관 롤플레잉을 하지 않는다.  
우리는 **Everything as Code**, W3C 디자인 토큰, 견고한 TypeScript/Next.js 기반으로 실전 프로덕트를 짓는 엔지니어이자 디자이너이다.  
우리의 시각적 표현은 **「신문지(Newsprint) 활판 인쇄술(Letterpress)」**의 정갈함과 지적 신뢰성에 뿌리를 둔다.

---

## 2. 85:15 조형 헌법 (The 85:15 Rule)

소나기 생태계의 모든 화면과 그래픽은 다음의 황금비율을 엄격히 준수한다.

```
┌─────────────────────────────────────────────────────────────┐
│ [ 85% 시스템 골격 ] : 신문 브로드시트 & 활판 인쇄 모더니즘   │
│  • 1px / 2px 단단한 헤어라인 실선 (The True 2px Stem)       │
│  • 신문 칼럼 그리드, 단정한 세리프(Cormorant/마루부리) 위계   │
│  • 갓 인쇄된 잉크 블랙(#161616) & 미색 신문용지(#FBF9F5)     │
├─────────────────────────────────────────────────────────────┤
│ [ 15% 그래픽 악센트 ] : 절제된 민들레 보태니컬 에칭 (선화)   │
│  • 신문 칼럼 구석에 단색(1도)으로 정교하게 인쇄된 펜화      │
│  • 민들레 싹(Sprout), 씨앗(Golden Seed), 기사 종결 부호(❦)  │
└─────────────────────────────────────────────────────────────┘
```

- **85%의 골격**: 시스템을 지배하는 것은 장식이 아닌 **이성적이고 단단한 신문 조판 그리드**다.
- **15%의 악센트**: 민들레의 생명력은 화면을 휘감는 장식이 아니라, **정교한 1도 펜 선화 스팟 삽화(Spot Illustration / Vignette)**로만 절제되어 존재한다.

## 3. 절대 금지 안티패턴 (Strict Anti-Patterns)

에이전트나 작업자가 임의로 스타일을 오염시키는 것을 방지하기 위해 다음을 영구 금지한다:

1. **❌ 전면적 아르누보(Art Nouveau) 덩굴 장식 금지**:
   - 화면 전체를 휘감는 구불구불한 식물 테두리, 금박 그라디언트, 아르누보풍 여신/꽃 장식 절대 금지. (타로카드 숍, 판타지 게임, 빈티지 찻집화 원천 차단)
2. **❌ 과도한 가상 롤플레잉/박물관 놀이 금지**:
   - 라틴어 학명 표기, 가상 식물도감 번호, 채집지/서식지 롤플레잉, 가상 압인 씰 철거.
3. **❌ 스크린 가독성을 침범하는 텍스처 필터 금지**:
   - 활자를 흐리게 만드는 과도한 SVG FeTurbulence 필터나 무거운 질감 타일링 금지. 가독성은 텍스처보다 항상 우선한다.
4. **❌ 소프트 드롭 섀도우 및 네온 컬러 금지**:
   - 물리적 인쇄물에는 블러 처리된 그림자가 없다. 단단한 2px 경계선과 Crisp Shadow만 허용한다.

## 4. 3대 조형 기둥 (The Three Pillars)

### Pillar 1: The True 2px Stem (단단한 줄기와 중심축)

- 모든 테두리와 구분선, 심볼의 중심축은 정직한 2px 실선으로 연결된다.
- 이는 콘크리트 틈에서도 꺾이지 않고 하늘을 향해 뻗는 민들레 줄기이자, 엔지니어링의 신뢰성을 상징한다.

### Pillar 2: Weathered Stone Radius (풍화된 돌 틈의 여백)

- 모서리 라운딩은 과장된 알약 형태(Full-Pill)를 배제하고, 자연스럽게 풍화된 돌의 각도인 `4px / 6px / 8px`에 머문다.

### Pillar 3: Ink on Newsprint (잉크와 신문용지의 물성)

- **Ink Black (`#161616`)**: 눈이 피로하지 않은 깊은 활판 인쇄 잉크색.
- **Newsprint Cream (`#FBF9F5`)**: 표백되지 않은 재생 신문용지의 따뜻한 미색.
- **Dandelion Gold (`#D97706` / `#F59E0B`)**: 흑백 지면 위에 오직 한 점, 생명력을 부여하는 단 하나의 스팟 악센트 컬러.

---

## 5. 변경 및 거버넌스 규정

- 본 헌법은 소나기 공방의 최상위 시각 기준이며, 하위 프로젝트(블로그, 포트폴리오, 문서)는 본 헌법에 위배되는 그래픽 스타일을 임의로 도입할 수 없다.
- 본 헌법의 개정은 소나기 공방 메이커의 명시적 승인이 있을 때만 가능하다.
