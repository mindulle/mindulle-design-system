# 상업 사용 규칙 (Commercial Usage Rules)

이 규칙은 외부 고객과 협업자가 Mindulle Atelier와 Sonagi를 소개할 때 지켜야 하는 기본선입니다. 자산 파일의 제공은 상표, 저작권 또는 공동 캠페인 권리를 양도하지 않습니다. 불확실한 경우 사용 전에 승인을 요청하세요.

## 허용되는 기본 사용

- 공식 제품·문서·저장소를 출처와 함께 소개하는 비상업적 사용
- 승인된 프로젝트에서 제공된 원본 로고와 락업을 비율 변경 없이 배치하는 것
- 제품이 Sonagi 생태계와 연동되거나 공식적으로 지원됨을 설명하는 참조 사용
- 공식 색상·타이포그래피·모티프를 이 가이드의 규격 안에서 사용하는 것

## 사전 승인이 필요한 사용

- 유료 서비스, 광고, 상품, 패키지, 강의, 행사, 출판물에 로고를 사용하는 경우
- 고객사 브랜드와 Mindulle/Sonagi를 같은 크기의 공동 락업으로 조합하는 경우
- 파트너십, 인증, 공식 리셀러·통합 파트너·후원 관계를 암시하는 경우
- 로고를 새 색상·문구·형태로 변형하거나 새로운 파생 마크를 만드는 경우
- 상표 출원, 도메인·앱 이름·제품 이름에 `Mindulle`, `Sonagi` 또는 공식 제품명을 포함하는 경우

## 금지

| 금지 사례                                     | 이유                         |
| --------------------------------------------- | ---------------------------- |
| 로고를 늘리기·찌그러뜨리기·기울이기           | 브랜드 비례와 인식 훼손      |
| 로고 위에 텍스트·사진·테두리를 겹치기         | `1X` 안전 여백 침범          |
| 임의의 그림자·그라디언트·외곽선·색상 적용     | 공식 자산의 조형 언어 훼손   |
| 공식 보증·제휴·인증처럼 보이게 사용           | 관계에 대한 오인 유발        |
| 제품 BI와 MDS-27 아이콘을 재명명하거나 재배포 | 시스템 명명 및 저작권 혼선   |
| 혐오·불법·기만·정치 캠페인과 결합             | 브랜드 가치와 안전 기준 위반 |

## 표기와 전달

- 첫 노출에는 `Mindulle Atelier` 또는 `Sonagi`의 공식 표기를 사용합니다.
- 제품을 언급할 때는 제품명과 사용한 자산 버전을 기록합니다.
- “공식”, “인증”, “파트너” 같은 표현은 서면 승인이 있을 때만 사용합니다.
- 공동 제작물에는 `Brand assets used under permission`와 같은 권리 표기를 승인 조건에 맞게 포함합니다.
- 접근성을 위해 로고에는 의미 있는 대체 텍스트를 제공하고, 로고만으로 정보를 전달하지 않습니다.

## 승인 요청에 포함할 내용

1. 사용 주체와 프로젝트 URL
2. 사용하려는 자산 경로·버전·배경
3. 노출 위치, 매체, 국가, 기간
4. 유료 여부와 예상 배포 범위
5. 공동 브랜드 또는 제품 관계에 대한 설명

승인은 저장소 이슈 또는 Mindulle Atelier 브랜드 담당자에게 요청합니다. 승인이 없는 상업 사용은 언제든 중단·수정 요청의 대상이 될 수 있습니다.
