# 공개 브랜드 가이드 (Public Brand Guide)

> **"겨울 끝, 민들레. 도구는 단단하게, 일상은 자유롭게."**  
> (At Winter's End, Dandelion.)

이 페이지는 외부 고객·협업자·제작자가 **Mindulle Atelier**와 **Sonagi**를 올바르게 소개하고 사용할 수 있도록 만든 공개 요약본입니다. 법적 권리의 양도나 상표 라이선스를 대신하지 않으며, 실제 배포에는 [Commercial Usage Rules](./commercial-usage)를 함께 적용합니다.

## 한 문장으로 이해하기

**Mindulle는 브랜드의 영혼과 공방을, Sonagi는 그 공방에서 만든 도구 생태계를 뜻합니다.** 로고를 장식처럼 반복하기보다 축은 구조를 세우고, 곡선은 시선을 운반하며, 씨앗은 도착점을 표시합니다.

---

## 🏛️ 삼위일체 브랜드 위계 (The Trinity Hierarchy)

민들레 생태계의 브랜드 위계는 감정적 본질에서 기술적 실행으로 수직 전개됩니다.

| 계층       | 명칭                                         | 상징 및 역할                                        | 전용 서체                              |
| :--------- | :------------------------------------------- | :-------------------------------------------------- | :------------------------------------- |
| **Tier 1** | **민들레 영혼 (The Soul)**                   | 인간의 존엄, 다정함, 겨울 끝의 생명력               | `Cormorant Garamond 700`               |
| **Tier 2** | **민들레 공방 CI (The Atelier Master Seal)** | 비대칭 돛과 황금 씨앗(True 2px Stem Emblem)         | `Cormorant Garamond` + `Noto Serif KR` |
| **Tier 3** | **소나기 도구군 BI (The Sonagi Engine)**     | AI-Native 도구 생태계 (`draw`, `graph`, `anvil` 등) | `Pretendard`, `JetBrains Mono`         |

> **공식 패밀리 락업 (Official Lineage)**:  
> `"Crafted by Mindulle Atelier • Powered by Sonagi Engine"`

---

## 3대 조형 원칙 (Three Pillars)

1. **The True 2px Stem (2px 기둥 법칙)**:
   - 모든 메인 축, 프레임, 아이콘 선화는 서브픽셀 번짐이 없는 정확한 2.0px 솔리드 스트로크를 준수합니다.
2. **Weathered Stone 4px/6px Radius (자연석 반경)**:
   - 과도한 원형(Pill shape)을 배제하고, 비바람에 깎여 나간 자연석의 묵직한 질감을 전달하는 단계별 라운딩(`4px`, `6px`, `8px`, `12px`)을 적용합니다.
3. **No Soft Shadows (소프트 섀도우 배제)**:
   - 40px 이상의 뿌연 블러 그림자를 배제하고, 빛과 각도에 의한 단단하고 명료한 크리스프 엘리베이션만 허용합니다.

---

## 색상과 대비

- 화면은 **60% 캔버스 / 30% 구조 / 10% 영혼의 포인트**로 운용합니다.
- 밝은 화면의 기본은 `#fcf2f0`, 어두운 화면의 기본은 `#1c1412`입니다.
- 구조는 `#47211b`, `#392d2b`, `#95817f`를 사용하고, 골드 포인트는 `#ffd166`~`#d97706` 범위에서 한 화면에 한 번만 강하게 사용합니다.
- 본문과 배경은 WCAG AA 대비를 확인하고, 골드를 본문 텍스트 색상으로 사용하지 않습니다.

## MDS-28 모티프 언어

| 모티프         | 역할             | 공개 사용 기준                                         |
| -------------- | ---------------- | ------------------------------------------------------ |
| **Sail Arc**   | 흐름과 이동      | 2px 라운드 선, 8px 그리드, 64px 이상 반복 간격         |
| **Seed Orbit** | 작은 시작과 도착 | 8–12px 코어, 짧은 3방향 방사선, 강한 골드는 화면당 1회 |
| **Axis Frame** | 구조와 신뢰      | 2px 축·베이스, 4px 코너, 그림자와 그라디언트 금지      |

세 모티프의 기준 시안은 [MDS-28 Figma Brand Identity Board](https://www.figma.com/design/AEoW19jmlUh3rFgzhhV1vH/Mindulle-Design-System-v0.1.0?node-id=429-3223)에서 확인할 수 있습니다. 코드 적용 규격은 [Graphic Motif System](https://github.com/mindulle/mindulle-design-system/blob/main/docs/brand-motif-system.md)을 따릅니다.

## 인쇄와 다음 단계

민들레 아틀리에는 디지털 화면(RGB)뿐 아니라 충무로/을지로 인쇄 공장으로 직접 발주 가능한 사전 출력(Pre-press) 공학 규격을 `@mindulle/brand-assets` 내에 통합 관리합니다.

- **명함 (Business Card)**: 90x50mm (사방 3mm 도련 적용 96x56mm), 엑스트라 매트 350g/m²
  - Front: 웜 페이퍼 라이트 모드 (K100 단색 텍스트 오버프린트)
  - Back: 리치 블랙 (`C20 M20 Y20 K100`) + 골드 엠블럼
- **원형 브랜드 스티커**: 지름 60mm 무광 코팅

자세한 자산 목록과 다운로드 경로는 [Brand Assets](./assets), 허용·금지 범위는 [Commercial Usage Rules](./commercial-usage)에서 확인합니다. 원본 파일을 변형하거나 재배포하지 말고, 승인이 필요한 경우 아래 문의 경로를 사용하세요.
