# 브랜드 자산 (Brand Assets)

공식 자산은 저장소의 `packages/brand-assets/`에 버전 관리됩니다. 가능한 경우 SVG 원본을 사용하고, 화면·인쇄에 맞는 테마와 최소 크기를 선택합니다. 임의로 다시 그리거나 추적한 파일은 공식 자산이 아닙니다.

## 자산 선택표

| 필요한 것        | 공식 경로                                       | 권장 사용                            |
| ---------------- | ----------------------------------------------- | ------------------------------------ |
| 마스터 인장      | `01_master_seal/dark/`, `01_master_seal/light/` | 공식 문서, 계약서, 인증, 포털 헤더   |
| 가로 락업        | `02_lockups/horizontal/`                        | 웹 헤더, README, 프레젠테이션        |
| 세로 락업        | `02_lockups/vertical/`                          | 모바일 스플래시, 패키지, 표지        |
| Sonagi 제품 BI   | `03_product_bi/`                                | 제품 소개, 도구 선택 화면, 제품 문서 |
| 파비콘·소셜 카드 | `04_touchpoints/`                               | 웹 브라우저, OG 카드, 소셜 채널      |
| 인쇄 템플릿      | `05_physical/`                                  | 명함, 스티커, 실물 굿즈              |

## 최소 크기와 안전 여백

- 인장 풀버전: 화면 `64×64px` 이상, 인쇄 `20×20mm` 이상
- 인장 심볼 버전: 화면 `32×32px` 이상, 인쇄 `10×10mm` 이상
- 가로 락업: 화면 너비 `160px` 이상, 인쇄 너비 `45mm` 이상
- 안전 여백: 자산의 기준 단위 `1X`를 네 방향에 확보합니다. 다른 텍스트, 선, 모티프가 이 구역을 침범하지 않습니다.
- `16×16px` 파비콘은 텍스트 없는 단순 심볼만 사용합니다.

## 배경과 출력

1. 밝은 배경에는 `light`, 어두운 배경에는 `dark` 자산을 사용합니다.
2. 로고에 별도 그림자, 외곽선, 그라디언트, 필터를 추가하지 않습니다.
3. 인쇄는 3mm 도련 안쪽에 배치하고, 로고 안전 여백은 재단선 밖으로 확장하지 않습니다.
4. RGB 화면용 파일을 인쇄용으로 임의 변환하지 말고, 제공된 PDF/SVG 또는 인쇄 템플릿을 사용합니다.

## 다운로드와 버전 고정

공개 배포물에는 `@mindulle/brand-assets`의 버전과 사용한 파일 경로를 기록합니다. 최신 패키지는 `packages/brand-assets/dist/mindulle-brand-kit-v0.1.0.zip`에서 확인할 수 있으며, 파일이 업데이트되면 기존 배포물과 섞지 않고 버전을 고정합니다.

> 자산을 내려받았다고 상표 사용권이 자동으로 부여되는 것은 아닙니다. 상업·공동 브랜딩은 [Commercial Usage Rules](./commercial-usage)의 승인 절차를 따릅니다.
