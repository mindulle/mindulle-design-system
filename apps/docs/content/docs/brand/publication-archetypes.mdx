민들레 아틀리에의 모든 서비스는 동일한 <strong>상위 조형 언어(House Style: 85:15 비율, 1px/2px 실선, 4px 곡률, 플랫 표면, 골드 악센트)</strong>를 공유합니다. 다만 출판사가 단행본·매거진·신문을 같은 종이와 잉크로 찍되 판형을 다르게 가져가듯, 각 웹사이트는 목적에 따라 세 가지 아키타입 중 하나를 따릅니다.

## 3대 아키타입 비교 매트릭스

| 구분 | 코어 (Core Index · 심플) | 디자인 시스템 문서 (Magazine · 매거진) | 블로그 (Broadsheet · 신문) |
| :--- | :--- | :--- | :--- |
| **핵심 역할** | 정체성 요약 · 서비스 진입점 | 시각 쇼케이스 + 실무 레퍼런스 | 에세이 · 기술 아티클 발행 지면 |
| **대표 지면** | 루트 코어, 쇼룸 인덱스 | `design.sonagi.space` 랜딩 · `/docs` | `blog.sonagi.space` 전 페이지 |
| **여백 · 밀도** | 낮음 (여백 중심, 최소 요소) | **이원화** (랜딩/브랜드는 여유, `/docs`는 실무 밀도) | 높음 (신문 지면 · 칼럼 호흡) |
| **서체 비중** | 세리프 타이틀 + 산세리프/모노 | 랜딩 세리프 H1 + 본문 산세리프·코드 | 헤드라인·본문 세리프 주력 + 모노 메타 |
| **허용 장식** | `1px` 구분선, 최소 선화 1개 | `2:1` 스페시멘, 인터랙티브 뷰어 | 마스트헤드, 드롭캡, `65:35` 칼럼, 종결 인장 |
| **금지 요소** | 다단 칼럼, 드롭캡, 카드 남발 | 신문 마스트헤드 강제, 과도한 본문 세리프 | 둥근 카드, 소프트 섀도우, 이질적 컬러 배지 |

## Tier 3 앱별 적용 기준

* **`sonagi-design-system` (`design.sonagi.space`):** 랜딩 히어로(`HERO-SPEC.md`의 `64px` H1 + `2:1` 워크벤치)와 [마스터 브랜드 북](./index) 스페시멘은 매거진 아키타입, 일반 `/docs` 본문은 가독성 중심 레퍼런스 레이아웃을 유지합니다.
* **`blog-sonagi-space` (`blog.sonagi.space`):** `/about`뿐 아니라 메인(`/`), 목록(`/blog`), 글 상세 전반에서 신문 아키타입(세리프 헤드라인, 플랫 헤어라인, 일관된 구분선)을 일관되게 적용하고, 둥근 카드나 이질적 컬러 배지 같은 하우스 스타일 이탈 요소를 배제합니다.
