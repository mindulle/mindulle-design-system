# 색상 토큰 (Color Tokens)

> 💡 **브랜드 헌법 연동**: 모든 색상 토큰은 [민들레 마스터 브랜드 북 (The Master Brand Book)](/docs/brand)의 **85:15 신문지 활판 인쇄 헌법**에 따라 운용됩니다. 신문지 지면은 별도 토큰 세트가 아니라 **표면 스코프**로 구현합니다 — `data-surface="editorial"`을 적용하면 `background/*`·`text/*`·`border/*`·`brand/*` 값이 종이·잉크 팔레트로 재매핑됩니다.

민들레 디자인 시스템은 OKLCH 기반으로 정밀 조율된 2-Tier W3C 표준 토큰 구조를 채택합니다.

- **Tier 1 (Primitives)**: 원시 색상 팔레트. UI에서 직접 참조하지 않습니다.
- **Tier 2 (Semantics)**: 의미 기반 시맨틱 토큰. 컴포넌트는 오직 이 토큰만을 참조합니다.

## CSS 변수 직접 사용법

CSS 모듈이나 인라인 스타일에서 `--mds-*` 접두사의 변수를 직접 호출할 수 있습니다:

```css
.my-card {
  background-color: var(--mds-color-bg-surface);
  color: var(--mds-color-text-primary);
  border: 2px solid var(--mds-color-border-default);
  border-radius: var(--mds-radius-md);
}
```
