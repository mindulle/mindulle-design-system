# 깊이 (Elevation)

깊이는 **3단계**만 사용합니다. 표면 명도로 위계를 만들고, 그림자는 최소한으로만 더합니다.

| 단계 | Effect Style | 값 | 용도 |
| :--- | :--- | :--- | :--- |
| **Flat (0)** | `Elevation/Flat (0)` | 없음 | 기본 콘텐츠 영역 |
| **Raised (1)** | `Elevation/Raised (1)` | `0 2px 6px rgba(40,20,15,0.08)` | 카드, 고정 헤더 |
| **Floating (2)** | `Elevation/Floating (2)` | `0 8px 24px rgba(40,20,15,0.15)` | 드롭다운, 모달, 토스트 |

## 포커스 링

| 모드 | Effect Style | 값 |
| :--- | :--- | :--- |
| Light | `Elevation/Focus Ring` | `0 0 0 3px rgba(184,106,4,0.25)` |
| Dark | `Elevation/Focus Ring` | `0 0 0 3px rgba(255,200,55,0.35)` |

## 사용 규칙

- 그림자는 **떠 있는 요소에만** 사용합니다. 정적 섹션에는 보더와 여백으로 구분합니다.
- 입력 요소에는 그림자를 쓰지 않고, 보더 + 포커스 링으로 상태를 표현합니다.
- 포커스 링은 **항상 표시**하며 제거하지 않습니다 (`outline: none` 금지).
- 두 단계 이상의 그림자를 동시에 중첩하지 않습니다.
