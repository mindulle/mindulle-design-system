# 그래픽 모티프 (Graphic Motifs)

MDS의 그래픽 모티프는 로고를 반복하는 장식이 아니라 **구조·흐름·도착점**을 전달하는 재사용 가능한 문법입니다.

    <p>완료 상태, 빈 상태, CTA의 시각적 도착점으로 사용합니다.</p>

  </div>
</div>

## 적용 원칙

- 화면당 강한 골드 포인트는 한 번만 사용합니다.
- 모티프 선은 항상 **True 2px**이며 8px 그리드에 스냅합니다.
- 로고 안전 여백과 모티프 사이에는 최소 1X를 둡니다.
- 모티프는 카드 안에 카드처럼 중첩하지 않습니다.

> 전체 분석·인쇄·모션 규격은 [`docs/brand-motif-system.md`](https://github.com/mindulle/mindulle-design-system/blob/main/docs/brand-motif-system.md)에서 확인할 수 있습니다.
