# 타이포그래피 (Typography)

민들레 디자인 시스템(MDS)은 **"정갈한 분석(Analytics)과 시적 에디토리얼(Editorial)"**의 만남을 지향합니다. 본문과 UI 요소에는 높은 가독성의 `Pretendard / Inter` 고딕 스택을 채택하고, 히어로 선언문과 전시관·인용부에는 영문 `Cormorant Garamond`와 국문 `Noto Serif KR / MaruBuri` 기반의 한국어 시네마틱 디스플레이 스택을 적용합니다.

## 토큰 표

| 토큰 | 값 | 용도 |
| :--- | :--- | :--- |
| `--mds-font-cinematic-display` | `'Cormorant Garamond', 'Noto Serif KR', Georgia, serif` | 히어로 헤드라인, 3D 쇼룸 타이틀 (≥36px) |
| `--mds-font-editorial-humanist` | `'Cormorant Garamond', 'MaruBuri', Georgia, serif` | 아틀리에 에세이, 매니페스토, 인용구 |
| `--mds-font-sans` | `'Pretendard', 'Inter', system-ui, sans-serif` | 버튼, 폼, 테이블, 본문 레이블 (11px~18px) |
| `--mds-font-serif` | `'Noto Serif KR', 'Merriweather', Georgia, serif` | 장문의 서술형 스토리텔링 본문 |
| `--mds-font-mono` | `'JetBrains Mono', 'Fira Code', monospace` | 코드 블록, 터미널, 데이터 수치 표기 |

## 코드 사용법

### 1. Tailwind CSS 유틸리티 클래스

```tsx
// 1) 시네마틱 히어로 타이틀
<h1 className="font-cinematic text-5xl font-bold tracking-tight text-white">
  겨울 끝, 민들레의 비상
</h1>

// 2) 에디토리얼 감성 부제 및 인용문
<p className="font-editorial text-2xl font-bold text-brand-primary">
  척박한 콘크리트 틈에서 피어나는 다정함
</p>

// 3) UI 기본 본문
<p className="font-sans text-sm text-zinc-400">
  16종 인터랙티브 컴포넌트와 W3C 시맨틱 토큰 매트릭스.
</p>
```

### 2. CSS 변수 직접 호출

```css
.hero-title {
  font-family: var(--mds-font-cinematic-display);
  font-weight: 700;
  font-size: 4rem; /* 64px */
  line-height: 1.15;
  letter-spacing: -0.025em;
}

.essay-quote {
  font-family: var(--mds-font-editorial-humanist);
  font-size: 1.5rem; /* 24px */
  line-height: 1.4;
}
```

## 사용 규칙

1. **2px True Stem (최소 기둥 두께 수호)**: 디스플레이 폰트 크기(≥36px)에서 세로 기둥의 실측 두께가 최소 2px(2.4px~2.8px) 이상이어야 합니다.
2. **Cormorant Garamond 광학 일치도**: `Noto Serif KR 700`(96% 조화도)과 `MaruBuri`를 공식 한글 매칭 서체로 사용합니다.
3. **용도별 스택 분리**: 세리프 디스플레이 스택은 히어로·제목·인용부에만 사용하고, **일반 UI 본문·폼·테이블에는 세리프나 모노스페이스 서체를 쓰지 않습니다**(`--mds-font-sans` 고정).
