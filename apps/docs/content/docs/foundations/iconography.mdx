# 아이코노그래피 (Iconography)

민들레 디자인 시스템(MDS v0.1.0)의 아이콘은 **"The True 2px Stem"** 조형 헌법에 따라 모든 코어 아이콘을 24×24 마스터 그리드와 **2.0px 솔리드 스트로크** 기준으로 운용합니다.

## 토큰 표

### Props 명세

| 토큰 / Prop | 값 (Default) | 용도 |
| :--- | :--- | :--- |
| `size` | `24` (`16` \| `20` \| `24` \| `32`) | 아이콘의 가로/세로 시각 크기(px) |
| `color` | `'currentColor'` | 획 색상 (부모 텍스트 색상 상속) |
| `strokeWidth` | `2` | 획 두께 (`The True 2px Law` 고정) |
| `className` | `''` | Tailwind 유틸리티 클래스 주입 |

### Core 9 네이밍 manifest

| 토큰 (Figma 인스턴스) | 값 (정식 Code export) | 용도 (레거시 별칭) |
| :--- | :--- | :--- |
| `Icon / MdsAddIcon / 2px` | `MdsAddIcon` | 추가 액션 (`SngAddIcon`) |
| `Icon / MdsArrowRightIcon / 2px` | `MdsArrowRightIcon` | 다음·이동 화살표 (`SngArrowRightIcon`) |
| `Icon / MdsCheckIcon / 2px` | `MdsCheckIcon` | 완료·선택 확인 (`SngCheckIcon`) |
| `Icon / MdsCloseIcon / 2px` | `MdsCloseIcon` | 닫기·취소 (`SngCloseIcon`) |
| `Icon / MdsDocumentIcon / 2px` | `MdsDocumentIcon` | 문서·페이지 (`SngDocumentIcon`) |
| `Icon / MdsHomeIcon / 2px` | `MdsHomeIcon` | 홈 이동 (`SngHomeIcon`) |
| `Icon / MdsMenuIcon / 2px` | `MdsMenuIcon` | 내비게이션 메뉴 (`SngMenuIcon`) |
| `Icon / MdsSearchIcon / 2px` | `MdsSearchIcon` | 검색 (`SngSearchIcon`) |
| `Icon / MdsUserIcon / 2px` | `MdsUserIcon` | 사용자·프로필 (`SngUserIcon`) |

정본 매니페스트는 `packages/icons/icon-manifest.json`이며, `pnpm --filter @mindulle/icons verify:naming`으로 3개 표면 정합성을 검증합니다.

## 코드 사용법

`@mindulle/icons` 패키지를 설치하여 독자 아이콘과 Lucide 확장 아이콘을 함께 사용합니다.

```bash
pnpm add @mindulle/icons
```

```tsx
import React from 'react';
import { MdsSearchIcon, MdsAddIcon } from '@mindulle/icons';
import { Sparkles, ShieldCheck } from '@mindulle/icons';

export function SearchHeader() {
  return (
    <div className="flex items-center gap-3">
      <MdsSearchIcon size={20} className="text-stone-700 dark:text-stone-200" />
      <span className="font-sans text-sm">통합 검색</span>
      <MdsAddIcon size={18} strokeWidth={2} />
    </div>
  );
}
```

## 사용 규칙

### 조형 헌법 (The 2px Icon Rules)

1. **The True 2px Law**: 모든 획 두께는 `strokeWidth={2}`를 고정합니다. **1.2px, 1.5px 등으로 임의 축소해 사용하지 않습니다.**
2. **24×24 마스터 그리드**: 기본 뷰박스는 `0 0 24 24`이며 정사각 비율 안에서 시각 무게 중심을 맞춥니다.
3. **Round Cap & Join**: `strokeLinecap="round"`와 `strokeLinejoin="round"`를 유지합니다.
4. **네이밍 규칙**: 신규 코드와 Figma 인스턴스에는 `Mds*Icon`을 사용하고, `Sng*Icon`은 레거시 호환용으로만 유지합니다.

### 접근성 사용 규칙

- **아이콘-only 컨트롤**: 접근 가능한 이름은 아이콘이 아니라 부모 `<button aria-label="...">`에 제공하고 아이콘에는 `aria-hidden="true"`를 붙입니다.
- **장식용 아이콘**: 인접 텍스트가 이미 의미를 전달하면 `aria-hidden="true"`로 중복 낭독을 막습니다.
- **터치 타깃 분리**: `16~32px`는 시각 크기이며, 상호작용 영역은 최소 `24px`(터치 UI는 `44px` 이상)을 확보합니다.
- **상태 구분**: 아이콘 색상만으로 상태를 구분하지 않고 텍스트·모양·`aria-*` 속성을 병행합니다.
