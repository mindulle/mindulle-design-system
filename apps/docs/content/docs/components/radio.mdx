# 라디오 (Radio)

이름(`name`)으로 그룹화되어 옵션 간 상호 배타적 선택을 보장합니다.

<ComponentPreview name="Radio" />

## Props 명세

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `name` | `string` | — | 라디오 그룹 식별자 |
| `value` | `string` | — | 라디오 선택 값 |
| `label` | `React.ReactNode` | — | 라벨 |
| `description` | `React.ReactNode` | — | 하단 보조 설명 |

## 접근성

- 네이티브 `<input type="radio">` 기반으로 `Tab`으로 그룹 진입 후 방향키(`Arrow`) 항목 전환과 `Space` 선택을 지원합니다. 동일 그룹 항목은 같은 `name` 속성으로 묶어야 합니다.
