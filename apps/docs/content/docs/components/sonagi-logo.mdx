# 소나기 로고 (SonagiLogo)

**레거시 컴포넌트입니다.** 2026년 브랜드 재정립(ADR 0013) 이전 로고로, 호환성을 위해서만 유지합니다. 신규 화면에는 [`MindulleLogo`](/docs/components/mindulle-logo)를 사용하세요.

```tsx
import { SonagiLogo } from '@mindulle/ui';

<SonagiLogo height={28} />
```

<ComponentPreview name="SonagiLogo" />

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `height` | `number` | `28` | 로고 높이(px) |

## 마이그레이션

```diff
- import { SonagiLogo } from '@mindulle/ui';
+ import { MindulleLogo } from '@mindulle/ui';

- <SonagiLogo height={28} />
+ <MindulleLogo size={28} />
```

## 정책

- 신규 코드에서 **import 금지** (ESLint 규칙 추가 예정)
- 문서·브랜드 자산에서도 소나기 표기는 인프라/엔진 문맥으로만 사용합니다.
