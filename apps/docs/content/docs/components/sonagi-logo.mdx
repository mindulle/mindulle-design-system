# 소나기 로고 (SonagiLogo)

**Tier 3(도구·인프라) 전용 워드마크입니다.** 브랜드 바이블 3-Tier 위계에 따라 대외 지면·블로그(Tier 1/2)에는 [`MindulleLogo`](/docs/components/mindulle-logo)와 `MINDULLE` 제호를 사용하고, `SonagiLogo`는 백엔드 엔진·CLI·개발 도구 문맥에서만 사용합니다.

- 중앙 스텐실 절개 마스크를 제거한 에디토리얼 워드마크
- 형광 민트(`#00ffcc`) 스팟을 제거하고 민들레 골드(`--mds-color-brand-primary`) 스팟 악센트로 통일

```tsx
import { SonagiLogo } from '@mindulle/ui';

<SonagiLogo height={28} />
```

<ComponentPreview name="SonagiLogo" />

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `height` | `number` | `28` | 로고 높이(px) |

## 사용 위계 (3-Tier Policy)

- **Tier 1 / 2 (스튜디오·블로그 등 대외 지면)**: [`MindulleLogo`](/docs/components/mindulle-logo) 사용
- **Tier 3 (엔진·도구·인프라)**: `SonagiLogo` 사용

## 접근성

- `<svg>` 브랜드 워드마크이므로 링크 내부에서는 부모 `<a>`에 `aria-label`을 두고 SVG에는 `aria-hidden="true"`를 권장합니다. 비인터랙티브 심볼이므로 키보드·포커스 동작은 해당 없습니다.
