# 민들레 로고 (MindulleLogo)

비바람을 가르는 비대칭 돛(Dynamic Wing-Sail)과 황금 씨앗(Golden Seed) 모티프를 담은 공식 SVG 컴포넌트입니다.
24×24 마스터 그리드 기반의 **True 2px Stem(최소 2px 기둥 두께)** 및 **4px Weathered Radius(마모된 모듈러 곡률)** 헌법을 완벽히 수호하여, 16px 파비콘부터 22~24px 헤더 내비게이션, 대형 전시 쇼룸까지 선명한 벡터 가독성을 보장합니다.

## 📐 조형 요소 구조 (Visual Anatomy)

| 구성 요소 | 기하학적 의미 및 스펙 | 적용 토큰/색상 |
| :--- | :--- | :--- |
| **01. Golden Seed Pod** | 대지에 뿌리내린 자아와 생명력의 기원 (하단 씨앗 본체) | `#ffd166` (Gold Core), `#f59e0b` (Stroke) |
| **02. The Main Mast** | 비바람에도 꺾이지 않는 당당한 줄기 (**True 2px Stem**) | `currentColor` / `#1c1514` (2px Solid Line) |
| **03. Dynamic Wing-Sail** | 봄바람을 안고 비상하는 비대칭 공기역학적 주 돛 | `fill-opacity="0.1"`, 1.8px Modular Curve |
| **04. Tension Spine** | 돛 날개 내부의 탄성을 지탱하는 황금 장력선 | `#ffd166` (1.4px Spine Arc) |
| **05. Top Jib Sail** | 상공의 제트기류를 포착하는 보조 상단 깃털 돛 | 1.5px Aerodynamic Feather |
| **06. Whispering Breeze** | 미래와 타자를 향해 뻗어나가는 은은한 바람결 | `#ffd166` (1.25px Dashed Breeze) |
| **07. Apex Lift Core** | 도약과 자유를 상징하는 돛대 최정점의 황금빛 섬광 | `#ffd166` Core & `#ffffff` Glint |

## Props 명세

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `number` | `32` | SVG 심볼 크기(width/height) |
| `theme` | `'auto' \| 'dark' \| 'light'` | `'auto'` | 렌더링 컬러 테마 |
| `withBackground` | `boolean` | `false` | 라운드 배경 박스 렌더링 여부 |

## 하위 호환성 (Backward Compatibility)

기존 레거시 코드의 중단을 방지하기 위해 `SonagiLogo`도 동일한 패키지에서 alias로 함께 제공됩니다:

```tsx
import { MindulleLogo, SonagiLogo } from '@mindulle/ui';

// 권장 (MDS v0.1.0)
<MindulleLogo size={40} />

// 레거시 호환
<SonagiLogo height={28} />
```
