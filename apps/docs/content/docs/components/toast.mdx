# 토스트 (Toast)

작업 결과나 시스템 상태를 **잠깐** 알려주는 비차단(非遮斷) 알림입니다. 사용자의 흐름을 멈추지 않아야 할 때 사용합니다.

```tsx
import { Toast } from '@mindulle/ui';

<Toast
  title="저장 완료"
  description="변경 사항이 반영되었습니다."
  type="success"
  onClose={() => setOpen(false)}
/>
```

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | — | 알림 제목 (필수) |
| `description` | `string` | — | 보조 설명 |
| `type` | `'info' \| 'success' \| 'warning' \| 'danger'` | `'info'` | 상태 색상 |
| `onClose` | `() => void` | — | 닫기 버튼 핸들러 (없으면 닫기 버튼 미표시) |

## 토큰

- 배경: `--mds-color-background-elevated`
- 상태색: `--mds-color-state-{info|success|warning|danger}`
- 곡률: `--mds-radius-lg` (12px)
- 그림자: `Elevation/Floating (2)`

## 사용 규칙

- **자동 닫힘 타이머는 앱 레이어**에서 제어합니다 (컴포넌트는 표현만 담당).
- 같은 화면에 3개 이상 쌓지 않습니다. 반복 알림은 배지나 인라인 메시지로 대체합니다.
- 사용자의 확인이 필요한 오류는 토스트 대신 **Modal**을 사용합니다.
