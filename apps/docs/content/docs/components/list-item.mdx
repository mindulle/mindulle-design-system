# 리스트 아이템 (ListItem)

카드나 모달 내부에서 행(Row) 단위의 데이터 항목을 일관되게 표현합니다.

<ComponentPreview name="ListItem" />

## Props 명세

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `React.ReactNode` | — | 항목 주요 제목 |
| `description` | `React.ReactNode` | — | 항목 부차적 설명 |
| `onClick` | `() => void` | — | 클릭 이벤트 핸들러 |

## 접근성

- 기본 `<div>` 컨테이너이므로 단순 표시 용도일 때는 키보드·포커스 동작이 해당 없습니다. 클릭 가능한 목록 항목으로 사용할 때는 내부 `<a href>`/`<button>`을 두거나 `role="button"`, `tabIndex={0}`, `Enter`/`Space` 핸들러를 함께 제공합니다.
