# 셀렉트 (Select)

커스텀 SVG 셰브론 아이콘과 시스템 기본 드롭다운 메뉴를 결합한 접근성 표준 셀렉트입니다.

<ComponentPreview name="Select" />

## Props 명세

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `placeholder` | `string` | — | 미선택 시 기본 힌트 |
| `error` | `boolean` | `false` | 유효성 에러 여부 |
| `disabled` | `boolean` | `false` | 비활성화 여부 |

## 접근성

- 네이티브 `<select>` 요소를 사용해 `Tab` 포커스 이동 및 `Space`/`Enter`/방향키 옵션 탐색을 지원하며, 키보드 포커스 시 `focus-visible:ring-2` 포커스 링이 노출됩니다.
