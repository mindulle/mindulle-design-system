# Hero Copy & Visual Spec (MDS-39)

`apps/docs/app/page.tsx` 랜딩 히어로의 재발 방지 규격입니다.

## 1. 레이아웃 아키텍처 (F안 · Option A — 상단 컴팩트 + 하단 풀폭 워크벤치)

- **구조**: 블로그(`Option C` 좌 카피·우 민들레 스팟)와 차별화하기 위해 **상단 컴팩트 카피/터미널·CTA 밴드 + 하단 풀폭 3열 `HeroVisual` 워크벤치** 구조를 사용합니다.
- **민들레 스팟 비중**: 워크벤치 3열 우측 모서리 15% 이하 스팟으로 제한합니다.
- **금지 요소**: 중앙 정렬 블러 글로우(`blur-3xl`), 알약(`rounded-full`) 배지, 그라디언트 텍스트, 면 채우기·그림자·설계도 점선

## 2. 카피 규격 (상한)

| 요소 | 규격 | 현재 값 |
| --- | --- | --- |
| **제목 (`<h1>`)** | 2줄 · 40자 이내 | `겨울 끝, 민들레 / 실무용 디자인 시스템` (21자) |
| **서브카피 (`<p>`)** | 2문장 · 120자 이내 | `W3C 시맨틱 토큰과 22종 React 19 컴포넌트로 구성한 한국어 에디토리얼 UI 시스템입니다.` (49자) |
| **CTA 버튼** | 2개 이하 | `Quickstart` (`/docs`), `22 Components` (`/docs/components/button`) |

## 3. 색상·선화 문법
