# Hero Copy & Visual Spec (MDS-51)

`apps/docs/app/page.tsx` 랜딩 히어로의 재발 방지 규격입니다. (MDS-39 F안 기반 → MDS-51 Carbon식 세로 호흡 및 2:1 비대칭 타일 고도화)

## 1. 레이아웃 아키텍처 (Carbon 2:1 Asymmetric Modular)

- **세로 호흡 (Above the fold ~860px):** 데스크톱(`1440px`) 기준 `<h1>`을 `64px`(`leading-[1.08]`)로 상향하고, 상하 여백(`py-16`, `gap-12`)을 확보해 납작함을 해소합니다.
- **2:1 비대칭 워크벤치 (`HeroVisual`):** 기존 균등 3열 + 하단 4열 퀵링크 스트립 대신 **좌측 2/3(`md:col-span-8`) 타이포·UI 스페시멘 캔버스 + 우측 1/3(`md:col-span-4`) 민들레 모노라인 스팟**으로 구성합니다.
- **여백 원칙:** 자잘한 미니 카드 남발을 피하고, 넓은 여백 위에 타이포 견본과 실물 크기 UI 프리미티브 2개 블록만 배치합니다.
- **민들레 스팟 비중:** 우측 1/3 타일 내 1px 모노라인 스팟으로 배치하며, 골드 악센트는 전체 화면 기준 15% 이하로 제한합니다.
- **금지 요소:** 중앙 정렬 블러 글로우(`blur-3xl`), 알약(`rounded-full`) 배지, 그라디언트 텍스트, 면 채우기·블러 그림자·설계도 점선

| **서브카피 (`<p>`)** | 2문장 · 120자 이내 | `W3C 시맨틱 토큰과 22종 React 19 컴포넌트로 구성한 한국어 에디토리얼 UI 시스템입니다.` (49자) |
